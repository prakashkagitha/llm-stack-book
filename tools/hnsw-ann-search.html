A brute-force scan is O(N) distance computations and always exact. HNSW replaces the scan with a walk: each node keeps up to M links to nearby vectors, and a node's top layer is drawn from an exponentially decaying distribution (level = floor(−ln U · mL), mL = 1/ln M), so layer sizes shrink geometrically and the top layer holds a handful of nodes with very long links. Search descends that hierarchy with a beam of width 1 — pure greedy hill-descent, a coarse-to-fine zoom — and only in layer 0 opens the beam to ef. Each hop evaluates just the current node's neighbors, so the total work grows like O(M · log N), not N. Three experiments, each reproducible in the panels above:

1. The scaling gap is the whole point. Set ef = 6 and sweep N from 8 to 60, watching the mean-cost dot on the chart. The scan cost is the N slider's own value; the HNSW cost goes from roughly 12 to roughly 26. Seven and a half times the data, barely double the work — and note the crossover: at N = 8 the walk costs more than the scan. A hierarchy only pays for itself once N is large, which is why nobody indexes a thousand vectors.

2. “Approximate” means measurably wrong, sometimes. Two different failures hide behind a low recall number. With ef < k the beam cannot even hold k results, so recall is capped at ef/k for arithmetic reasons — always set ef ≥ k. The real failure is the one the true nearest neighbor MISSED card reports: drop ef to 1 or 2 and drag the query into the gap between two clusters, and the greedy walk settles into a local minimum and returns a neighbor that is not the nearest. That is the tax you pay for the speedup, and it is why recall must be measured against brute force, never assumed.

3. Diverse links beat close links. Push N to 60, then flip neighbor selection to M closest and watch layer 0 thicken: the link counter jumps from 142 to 284. Twice the links, all of them spent pointing back into the same cluster, because the nearest M candidates to a node inside a dense blob are all in that blob. Look at the sweep chart now: the recall curve stops at about 0.79 and stays there however far you push ef — some blobs have lost the bridge the walk needs to cross, and a wider beam cannot reach a component it can never enter. The paper's relative-neighborhood rule spends each link on a distinct direction out of the node instead, and reaches recall 1.0 on the same data with half the links. That is why Algorithm 4 exists.

Real indexes are this same code in 768 dimensions, where the picture is impossible to draw but the mechanics are identical.
